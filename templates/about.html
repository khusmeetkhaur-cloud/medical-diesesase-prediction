About Medical Disease Prediction

HomeProjectContact

The Medical Disease Prediction System is a Machine Learning based web application developed using Python, Flask, Pandas, NumPy and Scikit-Learn.

Users can enter patient details such as age, BMI, blood pressure, glucose level, cholesterol, heart rate and lifestyle factors. The trained model analyzes these values and predicts the possible disease category.

Technologies Used

  • Python
  • Flask
  • Pandas
  • NumPy
  • Scikit-Learn
  • HTML and CSS
